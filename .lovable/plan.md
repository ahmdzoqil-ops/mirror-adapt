# نسخ مشروع "دفتر ديون" من GitHub إلى هذا المشروع

المستودع `ahmdzoqil-ops/dafter-dayoun` عام ويمكن الوصول إليه. وهو مبني على نفس تقنيات هذا المشروع (TanStack Start + React + Tailwind v4 + shadcn)، لذلك يمكن نسخه بالكامل هنا والعمل عليه مباشرة.

## ما سيتم عمله

1. جلب كل ملفات المستودع من فرع `main` ونسخها فوق ملفات المشروع الحالي:
   - الصفحات: الرئيسية، صفحة العميل `client/$id`، صفحة المشاركة `share`
   - الأقسام: اليومية، المدينون، الدفعات، التقارير، الإعدادات، سلة المحذوفات
   - المكونات: قفل التطبيق، مركز التنبيهات، حوار الحركة، إدخال الصور، حوار التقارير وغيرها
   - مكتبات المنطق: التخزين المحلي، النسخ الاحتياطي، البصمة، جهات الاتصال، PDF، المشاركة، التنسيق العربي، PWA
   - ملفات `public` (الأيقونات، manifest) وإعدادات Vite وTailwind والتصميم
2. تثبيت الحزم الإضافية التي يحتاجها المشروع المنسوخ: `jspdf`, `html2canvas-pro`, `recharts`, `date-fns`, `cmdk`, `embla-carousel-react`, `vaul`, `input-otp`, `react-hook-form`, `vite-plugin-pwa` وبقية مكونات Radix.
3. تشغيل التطبيق والتحقق من أن الصفحات تعمل بدون أخطاء، وإصلاح أي مشاكل ناتجة عن اختلاف إصدارات القالب.

## ملاحظات تقنية

- سيتم استبدال `src/routes/index.tsx` و`__root.tsx` و`styles.css` و`vite.config.ts` بنسخ المستودع.
- `routeTree.gen.ts` يُعاد توليده تلقائيًا.
- لا توجد قاعدة بيانات في المشروع الأصلي (البيانات محلية في المتصفح)، فلا حاجة لتفعيل Cloud إلا إذا طلبت المزامنة بين الأجهزة لاحقًا.

## بعد النسخ

أخبرني بالتعديلات التي تريدها (تغيير التصميم، إضافة ميزات، ربط قاعدة بيانات...) وسأنفذها على النسخة.
